Import Existing Grade Sheet

Upload your existing Excel grade sheet (e.g., 5mPf7jb1-ClassRecord1stSem2627-OLD-BACKUP.xlsx) and it will automatically import all courses, students, and grades.

Supported Formats:

  • Excel files (.xlsx, .xls)
  • Multiple sheets (one per course)
  • Standard HCDC Class Record format
  • Columns: Student Name, ID Number, Email, Grades

What Gets Imported?

Courses

Each sheet becomes a course. Course code and title are extracted from sheet name.

Students

All students from each sheet are imported with their ID numbers and email addresses.

Grades

All grade columns are imported as grading components with their respective scores.

Components

Grade columns are automatically mapped to Prelim-Mid or Semis-Final components.

Import Options

Automatic Mapping

The importer automatically:

  • Detects course information from sheet names
  • Identifies student columns (Name, ID, Email)
  • Maps grade columns to Prelim-Mid or Semis-Final periods
  • Creates grading components for each grade column
  • Calculates final grades automatically

Notes

Important considerations:

  • Existing data will not be overwritten (new courses/students will be added)
  • Duplicate students (same ID number) will be skipped
  • Large files may take a few seconds to import
  • After import, review the data in the app and adjust as needed
